# EcoSort: A Smart Waste Segregation Assistant and Logger

## Overview
EcoSort is a simple program that helps users correctly identify whether a waste
item is Biodegradable, Non-biodegradable, or Recyclable. Users can look up an
item, log their daily waste disposal, and view a summary of what they've thrown
away over time.

## Problem It Solves
Many people aren't sure which bin an item belongs in, which leads to
contaminated recyclables and more waste ending up in landfills. EcoSort aims to
make correct waste segregation quick and easy for students and households.

## Planned Features
- Waste item lookup by keyword
- Built-in reference list of common waste items
- Daily waste logging with date tracking
- Category summary dashboard
- Input validation (rejects blank or unrecognized entries)
